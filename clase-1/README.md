# Clase 1 — Fundamentos de LLMs con modelos Llama

## Qué se aprende

- **De palabras a tokens:** cómo el modelo divide el texto en piezas y por qué importa el conteo.
- **Primera llamada a Llama (zero-shot):** pedir una tarea directamente, sin ejemplos.
- **Cuántos tokens consumió el prompt:** medir el costo de cada llamada.
- **Midiendo la latencia de inferencia:** cuánto tarda el modelo en responder.
- **Comparando dos tamaños de modelo:** qué cambia entre un modelo chico y uno grande.

## Challenge

Comparador de modelos Llama: llamar a dos tamaños de modelo con el mismo
prompt, medir tokens y latencia, y comparar las respuestas.
