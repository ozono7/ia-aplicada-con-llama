# Hackathon 1 — Asistente inteligente con Llama

[Ver esta carpeta en nbviewer](https://nbviewer.org/github/ozono7/ia-aplicada-con-llama/tree/main/hackathon-1)

## Qué se construye

Un asistente funcional con Llama, eligiendo las técnicas que tengan sentido
para el problema (prompting, RAG, fine-tuning, pipeline) y demostrando que la
solución funciona. No se trata de usar todas las técnicas a la vez, sino las
que el problema necesita.

## Ejemplo completo de entrega

**Asistente de Biblioteca con RAG (TinyLlama):** definición del proyecto,
problema, usuario objetivo, solución y criterio de éxito; decisión de
arquitectura (RAG, no fine-tuning, en este ejemplo); preparación del entorno,
carga de TinyLlama y base de conocimiento.
