# Clase 4 — Pipeline completo: de datos a modelo desplegado

## Qué se aprende

Esta clase une en un solo flujo lo visto en las tres anteriores:

1. **Paso 1 — Base de conocimiento (RAG):** recuperar información de documentos antes de responder.
2. **Paso 2 — Ajustar el tono (fine-tuning con LoRA):** afinar el modelo con datos propios.
3. **Paso 3 — Desplegar el modelo ajustado:** dejar el modelo disponible para usarlo.
4. **Paso 4 — Pipeline completo:** RAG + modelo ajustado trabajando juntos.
